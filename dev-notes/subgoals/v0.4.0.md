# v0.4.0 — Observability & test determinism (a11y, visual regression, interception)

## Objective
Give browsy-bot the observability and determinism that make it a credible
replacement for heavier browser-automation suites: accessibility-tree auditing,
visual-regression capture/compare, and network request interception/mocking.

## Context
Tier 1 (v0.3.0) closes the interaction gaps. Tier 2 adds capabilities that are
*hard* to get from generic CDP wrappers: reading the live accessibility tree,
diffing screenshots against a baseline in `dev-notes/browsy-captures/`, and
stubbing network requests so tests don't depend on live APIs.

## Deliverables
- [x] `src/core/a11y.ts` — `getAccessibilityTree(session)`:
      `Accessibility.enable` + `Accessibility.getFullAXTree`, return filtered AX
      nodes (role/name/value/state). Expose `browsy_a11y` tool.
- [x] `src/core/visual.ts` — `captureBaseline(session, name)` and
      `compareScreenshot(session, name, threshold?)`: capture to
      `dev-notes/browsy-captures/baselines/` and `dev-notes/browsy-captures/diffs/`,
      compute pixel diff, return pass/fail + diff image path.
      Minimal PNG decode (color types 2/6, bit depth 8, filters 0-4) with no extra deps.
- [ ] `src/core/intercept.ts` — `setRequestInterception(session, rules)`:
      `Network.setBlockedURLs` + `Fetch.enable`/`Fetch.requestPaused` +
      `Fetch.fulfillRequest`/`Fetch.failRequest` for stubbing. Expose
      `browsy_intercept` tool.
- [ ] `src/actions.ts` — wire a11y/visual/intercept into the public surface.
- [ ] `src/mcp.ts` — `browsy_a11y`, `browsy_visual_baseline`, `browsy_visual_compare`,
      `browsy_intercept` tools.
- [ ] `src/cli.ts` — `browsy a11y`, `browsy visual-baseline`, `browsy visual-compare`,
      `browsy intercept` commands.
- [ ] Tests: test/a11y.test.ts, test/visual.test.ts, test/intercept.test.ts
      (mocked CDP transport).
- [ ] Done when: `npm run typecheck && npm run build && npm test` all green.

## Risks
- Accessibility tree can be large; paginate/filter by relevance (role, name) to keep payloads small.
- Pixel diff needs a decode step; keep dependency footprint light (use `png-chunk-extract` or manual PNG parse, or ship a tiny pure-JS comparator).
- Fetch interception requires `Network.setCacheDisabled` care to avoid stale stubs.
