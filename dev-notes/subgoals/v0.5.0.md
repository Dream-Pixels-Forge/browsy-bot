# v0.5.0 — Stealth & session resilience (anti-detection, record/replay, cross-tab)

## Objective
Make browsy-bot robust against headless detection and give it session
durability: stealth mode, record & replay CDP sessions, and automatic
cross-tab coordination.

## Context
Sites increasingly block headless CDP (`navigator.webdriver`, missing plugins,
WebGL vendor strings). Teams also need to reproduce flaky failures offline and
work across popups/new tabs without manually tracking targetIds. v0.5.0 adds
these operational capabilities.

## Deliverables
- [x] `src/core/stealth.ts` — `enableStealth(session)`: override
      `navigator.webdriver` → undefined, spoof `plugins`, `languages`,
      WebGL renderer/vendor, `chrome` object, via `Page.addScriptToEvaluateOnNewDocument`.
- [x] `src/core/record.ts` — `recordSession(session, path)` / `replaySession(path)`:
      serialize CDP messages + events to NDJSON, replay against a mock transport
      for offline debugging and CI reproducibility.
- [ ] `src/core/tabs.ts` — `trackNewTabs(session)` / `switchToTab(session, targetId)`:
      listen for `Target.targetCreated`/`Target.targetDestroyed`, auto-discover
      popups, expose tab focus/switch helpers. ✅ DONE
- [ ] `src/actions.ts` — wire stealth/record/tabs into the public surface.
- [ ] `src/mcp.ts` — `browsy_stealth`, `browsy_record`, `browsy_replay`,
      `browsy_switch_tab` tools.
- [ ] `src/cli.ts` — `browsy stealth`, `browsy record`, `browsy replay`,
      `browsy switch-tab` commands.
- [ ] Tests: test/stealth.test.ts, test/record.test.ts, test/tabs.test.ts.
- [ ] Done when: `npm run typecheck && npm run build && npm test` all green.

## Risks
- Stealth overrides are page-lifetime; must inject before navigation and on every new document.
- Record/replay must handle binary data (screenshot base64) and large event streams without memory blowup.
- Cross-tab coordination needs target lifecycle events enabled per session.
